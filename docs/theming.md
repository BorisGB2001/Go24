# Оформление и темы go24

Внешний вид go24 полностью задаётся через CSS: цвета, шрифты, отступы, скругления и иконки. Чтобы его поменять, не нужно трогать шаблоны или код и не нужно пересобирать образ.

## Как устроены стили

| Файл | Что внутри | Когда менять |
|---|---|---|
| `internal/web/static/css/tokens.css` | **Переменные дизайна**: все цвета (включая тёмную тему), шрифты, размеры, отступы, тени, цвета статусов, параметры аватаров | Стандартный вид продукта |
| `internal/web/static/css/icons.css` | Соответствие иконки и файла: `.i-check { --icon: url(...) }` | Добавление или замена стандартных иконок |
| `internal/web/static/css/app.css` | Компоненты: меню, карточки, таблицы, кнопки, канбан. **Конкретных цветов и размеров здесь нет**, только переменные | Только при изменении раскладки |
| `deploy/theme/theme.css` | **Тема конкретной установки**, подключается последней и перекрывает всё выше | Своё оформление без пересборки |

## Своя тема без пересборки

1. Скопируйте `deploy/theme/theme.css.example` в `deploy/theme/theme.css`.
2. Переопределите нужные переменные из `tokens.css`:

```css
:root {
  --accent: #7c3aed;
  --side-bg: #2b1a47;
  --radius: 6px;
}
```

3. Обновите страницу. go24 проверяет наличие `theme.css` при каждом запросе, перезапуск не нужен.

Папка `deploy/theme/` смонтирована в контейнер как `/theme` (переменная `GO24_THEME_DIR`) и доступна в браузере по адресу `/theme/...`. Поэтому рядом можно класть шрифты, логотип и иконки и ссылаться на них из `theme.css`.

## Иконки

В разметке иконка — это пустой элемент `<i class="i i-NAME">`. Картинка задаётся в CSS переменной `--icon` и используется как маска, которая закрашивается цветом текста. Поэтому подходит **любой одноцветный SVG**: Tabler, Font Awesome, Material Symbols, свой рисунок. Цвет и размер иконки берутся из CSS: `color` и `--icon-size`.

Заменить одну иконку в теме:

```css
.i-checkbox { --icon: url("/theme/icons/my-tasks.svg"); }
```

Заменить весь набор: положить свои SVG в `deploy/theme/icons/` и переопределить в `theme.css` все классы `.i-*` (их список — в `icons.css`).

Стандартный набор — Tabler Icons outline (лицензия MIT, `internal/web/static/icons/LICENSE`). Новые иконки берутся оттуда же: SVG кладётся в `static/icons/`, строка добавляется в `icons.css`. Тест `TestIcons` проверяет, что каждая иконка из шаблонов существует и у каждого SVG есть класс в `icons.css`.

## Переменные (основные)

- `--accent`, `--accent-soft`, `--on-accent` — фирменный цвет, его светлый вариант и цвет текста на нём.
- `--side-bg`, `--side-bg-hover`, `--side-text`, `--side-text-active` — левое меню.
- `--bg`, `--card`, `--text`, `--muted`, `--line`, `--hover` — фон, карточки, текст, линии.
- `--ok`, `--warn`, `--danger`, `--violet` и их варианты `*-soft` — смысловые цвета.
- `--st-<статус>-bg` и `--st-<статус>-fg` — цвета статусов задач.
- `--ava-saturation`, `--ava-lightness`, `--ava-text` — аватары. Оттенок вычисляется из имени, остальное задаётся здесь.
- `--font`, `--font-size*`, `--radius*`, `--gap`, `--pad`, `--content-pad`, `--shadow`, `--icon-size`, `--side-width`.

Тёмная тема задаётся в `tokens.css` блоком `@media (prefers-color-scheme: dark)`. В своей теме его можно переопределить так же.
