# Мессенджер go24: Telegram, Matrix и другие — как связать

Пожелание пользователя (2026-10-12): сообщения из go24 реально уходят в мессенджер; группы go24 = группы
мессенджера; обсуждение задачи — тред в группе; всё закрыто от посторонних; уволенный теряет доступ
автоматически. Варианты: Telegram, Mattermost, Slack, Matrix.

## Общая схема (одна для всех мессенджеров)

go24 — источник прав. В коде интерфейс «провайдер мессенджера», администратор выбирает реализацию:

| go24 | Matrix | Telegram | Mattermost / Slack |
|---|---|---|---|
| Компания | Space (пространство) | — | Team / Workspace |
| Проект (группа) | Комната в Space | Супергруппа с «темами» | Канал (private) |
| Задача | Тред в комнате проекта (или своя комната) | **Тема (topic)** супергруппы проекта | Тред в канале |
| Личный чат | Личная комната | Личка с ботом / между людьми — вне go24 | DM |
| Участники проекта/задачи | invite / kick ботом go24 | ссылка-приглашение на 1 человека + ban | invite / remove |
| Увольнение | kick из всех комнат + деактивация учётки | ban во всех группах | deactivate |
| Вход | SSO через Authentik (OIDC) | Telegram-аккаунт, привязка через бота | SSO через Authentik |
| Где лежат сообщения | **у нас** (self-hosted) | в облаке Telegram | у нас / в облаке Slack |

Синхронизация двусторонняя: сообщение в чате задачи go24 → в тред мессенджера; ответ в мессенджере →
в чат задачи go24 (через webhook бота / application service).

## Matrix — рекомендую основным

- Полностью свой сервер (Synapse или лёгкий Conduit/conduwuit в Docker), клиенты Element — веб, iOS, Android, десктоп.
- Вход через Authentik (OIDC) — те же учётки; увольнение = блок в Authentik + kick ботом из всех комнат → доступ пропадает сразу.
- go24 работает как **application service**: сам создаёт пространства, комнаты, треды, приглашает и удаляет людей.
- Комнаты закрытые (invite-only, без публичного каталога), шифрование E2EE по желанию.
- Звонки — Element Call / LiveKit (см. `docs/calls.md`), голосовые сообщения встроены.
- **Мост в Telegram** (mautrix-telegram): кто хочет — пишет из Telegram, сообщения при этом хранятся и у нас.

## Telegram — вторым провайдером (с ограничениями платформы)

- Бот **не может создать группу** (Bot API этого не умеет). Поэтому: администратор один раз создаёт
  супергруппу на проект (или одну на компанию) с включёнными «Темами» и добавляет бота go24 администратором.
  Дальше бот сам: создаёт тему на каждую задачу (`createForumTopic`), пишет туда, закрывает тему при закрытии задачи.
- Бот **не может добавить человека** — только выдать персональную ссылку-приглашение (лимит 1 вход,
  с заявкой на вступление, которую бот одобряет только сотрудникам). Сотрудник один раз привязывает
  свой Telegram к go24 через бота (`/start` с одноразовым кодом).
- Увольнение: бот банит человека во всех группах компании (`banChatMember`) — доступ пропадает сразу.
- Посторонние: группа без публичной ссылки, вступление только по заявке, которую бот проверяет по go24.
- Минусы: переписка хранится в облаке Telegram (не self-hosted), на телефоне это личный аккаунт сотрудника.

## Mattermost / Slack

- Mattermost: self-hosted, SSO через Authentik (GitLab/OIDC), каналы и треды — простая интеграция по REST API.
- Slack: облако, всё делается API бота; для self-hosted продукта — как опция для клиентов, кто уже в Slack.

## Предлагаемый порядок

1. Чат внутри go24 (уже есть у задач) + интерфейс провайдера.
2. Matrix (свой сервер в Docker, SSO Authentik, application service) + мост в Telegram.
3. Telegram-бот как самостоятельный провайдер (супергруппы с темами).
4. Mattermost / Slack по запросу.

## Где хранится переписка (решение 2026-10-13)

**Вся переписка хранится в Matrix**: чат задач, лента (посты, комментарии, «Нравится»), личные и групповые чаты.
go24 пишет сначала в Matrix (от имени автора), и только потом добавляет запись в свою базу — это **индекс** для
быстрых списков, поиска и прав; его можно восстановить из Matrix. Если Matrix недоступен, запись не проходит,
человек видит ошибку и его текст остаётся в форме.

- Чат задачи: тред задачи в комнате проекта (или комната задачи для проектов «только участникам»).
  Старая переписка задачи (до мессенджера, импорт) переносится в Matrix при первом открытии треда — с исходными датами.
- Лента: «Лента компании» (все сотрудники) или комната проекта; комментарии — тред поста; «Нравится» — 👍.
- Мессенджер в go24 (/im) читает и пишет Matrix доступом самого сотрудника — каждый видит ровно свои чаты.
- Element — отдельный вход в тот же мессенджер; написанное там появляется в нужном месте go24 и наоборот.
