# Звонки, голосовые сообщения и телефония — выбор сервисов

Принцип как у хранилищ (rclone): **go24 не привязан к одному сервису**. Есть общий интерфейс в коде
(«провайдер звонков», «провайдер телефонии»), а администратор в настройках выбирает реализацию:
облачную или свою (self-hosted). Пользователи и задачи об этом не знают.

## Три разные задачи

| Что | Пример в корпоративном портале | Чем закрываем |
|---|---|---|
| Звонки внутри go24 (аудио/видео между сотрудниками, из чата задачи, «Чаты и встречи» группы) | звонок в мессенджере | **LiveKit** (рекомендуется) или Jitsi |
| Голосовые сообщения в чатах | кнопка микрофона в чате | **ничего внешнего не нужно**: запись в браузере (MediaRecorder, Opus) → файл в хранилище go24 (rclone) |
| Телефония (городские/мобильные номера, входящие/исходящие, запись, CRM-карточка звонящего) | Телефония (Voximplant + SIP) | **Asterisk** + SIP-транк любого оператора, или облачная АТС по API |

## 1. Звонки внутри go24 — LiveKit

- Открытый сервер (Apache 2.0, Go), WebRTC SFU: группы, демонстрация экрана, запись (Egress).
- **Один и тот же API** у self-hosted сервера и LiveKit Cloud — выбор «облако / свой» это только адрес и ключи
  в настройках go24. Ровно то, что нужно.
- go24 сам выдаёт токены на вход в комнату (Go SDK) — проверка прав по участникам задачи/чата, вход через Authentik.
- Свой сервер: один контейнер `livekit-server` (+ TURN встроенный), ставится в наш Swarm.
- Запись звонков (GO24DEV-454): контейнер `livekit-egress` (Chrome внутри записывает комнату сеткой видео или только
  звук) и `redis` (через него LiveKit отдаёт задания Egress). Egress пишет файл в общий том `call-recordings`
  (`GO24_RECORD_DIR`), go24-worker переносит его на Диск того, кто начал запись («Записи звонков»), и пишет в чат
  или задачу звонка. Включает администратор: «Настройки → Звонки».
- Внешние сервисы (GO24DEV-499): Zoom — POST /v2/users/{email|me}/meetings с токеном Server-to-Server OAuth
  (account_credentials); Яндекс Телемост — POST cloud-api.yandex.net/v1/telemost-api/conferences («OAuth <токен>»,
  telemost-api:conferences.create); VK Звонки — calls.start (токен пользователя VK ID, group_id — от сообщества) →
  join_link. У Telegram (Bot API) и Max (Bot API) звонков нет; групповой звонок Telegram по ссылке есть только в
  клиентском MTProto (phone.createConferenceCall) от живого аккаунта — не используем, сотрудники дают свои ссылки.

Альтернатива: **Jitsi Meet** (Apache 2.0, есть облако 8x8 JaaS). Проще «комната по ссылке», но тяжелее
(prosody + jvb + jicofo) и хуже встраивается в свой интерфейс. Подключаем вторым провайдером при необходимости.

Не рекомендую как основу: Matrix (Synapse + Element Call) — это целый мессенджер со своей моделью данных и
федерацией; правило «администратор не видит личные чаты» и наши права проще держать в своём коде.

## 2. Голосовые сообщения

Отдельный сервис не нужен: браузер пишет Opus/WebM, go24 сохраняет как вложение сообщения в выбранное
хранилище (встроенное, Nextcloud, S3…), чат показывает плеер. Расшифровка речи — позже, опционально
(Whisper в своём контейнере или облачный API — тоже на выбор).

## 3. Телефония — Asterisk (как и планировали)

- Self-hosted: **Asterisk** (GPLv2) в контейнере, go24 управляет им через **ARI** (REST + WebSocket):
  входящий звонок → всплывающая карточка, исходящий по клику, запись разговоров в хранилище, история звонков.
- Номера: SIP-транк **любого** оператора (облачная часть — только линия). Меняется в настройках.
- Сотрудники звонят из браузера (WebRTC → Asterisk) или с SIP-телефонов/софтфонов.
- Второй вариант провайдера: облачная АТС по API (Voximplant — её используют корпоративные порталы; Zadarma, Манго и т.п.) —
  для тех, кто не хочет держать свой Asterisk.

## Порядок работ (предложение)

1. Мессенджер go24 (личные и групповые чаты; чат задачи уже есть) + голосовые сообщения.
2. Звонки через LiveKit (свой сервер в Docker; облако — той же настройкой).
3. Раздел «Телефония»: Asterisk + ARI, затем облачный провайдер.

В левом меню разделы «Мессенджер» и «Телефония» появятся вместе с модулями (меню уже разбито на разделы).
