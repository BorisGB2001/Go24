# Языки интерфейса

Все тексты интерфейса, сообщения об ошибках и названия статусов вынесены в файлы переводов. В коде и шаблонах остаются только ключи.

| Где | Что |
|---|---|
| `internal/i18n/locales/ru-RU.json` | Русский, язык по умолчанию: при отсутствии ключа в другом языке берётся отсюда |
| `internal/i18n/locales/en-US.json` | English |
| `deploy/locales/<код>.json` | Языки и правки конкретной установки, без пересборки (подхватываются при перезапуске go24) |

Файл — плоский JSON `"ключ": "текст"`. Подстановки — как в `fmt.Sprintf`: `"err.project_key_taken": "Проект с ключом %s уже есть"`. Формат даты задаётся в самом языке (`format.datetime` в нотации Go: `02.01.2006 15:04` или `Jan 2, 2006 15:04`).

## Как выбирается язык

1. Явный выбор пользователя: ссылки языков внизу левого меню и на странице входа (`/lang/<код>`), запоминается в cookie на год.
2. Язык браузера (`Accept-Language`): точное совпадение (`en-US`), затем по основному языку (`en-GB` → `en-US`).
3. Иначе `ru-RU`.

REST API отвечает на языке из `Accept-Language`. В ошибках кроме текста есть стабильный `code` (ключ сообщения), по нему программы и проверяют ошибку.

## Добавить язык

- **Без пересборки:** скопировать `en-US.json` в `deploy/locales/de-DE.json`, перевести, сделать `make up`. Можно переводить не всё: недостающие ключи возьмутся из русского.
- **Встроить в продукт:** положить файл в `internal/i18n/locales/`. Тест `TestLocalesComplete` требует, чтобы во встроенных языках были все ключи.

## Правила для разработчиков

- В шаблонах: `{{t "nav.projects"}}`, с подстановкой `{{t "search.found" .Query (len .Data)}}`, для наборов значений `{{t (print "status." .Status)}}`.
- В Go: ошибки для пользователя — `i18n.E("err.ключ", аргументы…)`, ключ-аргумент — `i18n.Ref("status.completed")`. Русский текст в коде не пишем.
- В историю изменений записываются коды (`in_progress`, `2`, `true`, время в RFC 3339), а не текст: история показывается на языке читателя.
- Тест `TestMessageKeys` находит все ключи в шаблонах и Go-коде и проверяет, что они есть во всех языках. Тест отрисовки страниц ловит непереведённые ключи на странице.
