# Языки этой установки

Положите сюда `<код языка>.json`, например `de-DE.json` или `ru-RU.json`, и перезапустите go24 (`make up`).

- **Новый язык.** За основу возьмите `internal/i18n/locales/en-US.json` и переведите значения. Ключи, которых нет в файле, берутся из русского.
- **Правка встроенного перевода.** Положите `ru-RU.json`, в котором только нужные ключи, например `{"nav.my_tasks": "Мои дела"}`. Остальные ключи останутся стандартными.

`make sync` эти файлы на сервере не трогает. В git попадает только этот README.
